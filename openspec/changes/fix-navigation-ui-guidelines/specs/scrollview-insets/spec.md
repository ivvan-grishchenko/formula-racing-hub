## ADDED Requirements

### Requirement: All ScrollView components SHALL use contentInsetAdjustmentBehavior="automatic"
All ScrollView components in the app MUST have the contentInsetAdjustmentBehavior prop set to "automatic".

#### Scenario: ScrollView has automatic inset adjustment
- **WHEN** a ScrollView is rendered in the app
- **THEN** it includes `contentInsetAdjustmentBehavior="automatic"` prop
